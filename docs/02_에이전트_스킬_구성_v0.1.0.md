# 에이전트·스킬 구성 v0.1.0

> `C:\Source\기획\heythere_planer` 의 공용 에이전트/스킬 풀에서 이 프로젝트에 필요한 것만 선별.

## 1. 프로젝트 개요

- **프로젝트 명**: 주식 트렌드 알림 (stock_trend)
- **레포 경로**: `c:/정상민/주식트렌드`
- **기술 스택**: React 19 + TypeScript + Vite + Tailwind + shadcn (헤이데어 표준 준수) — 목업은 순정 HTML/Tailwind CDN
- **1차 스코프**: 종목 검색 · AI 분석 리포트 · 즐겨찾기 · 알림 조건 · 알림 이력

## 5. 헤이데어 자산 재사용 원칙

- 스킬 파일은 이 프로젝트로 **복사하지 않는다**. 원본 경로만 참조.
- 스킬을 수정해야 할 경우 헤이데어 planner 레포에 PR 을 낸다.
- 이 프로젝트만의 규칙(주식 분석 로직 등)은 **프로젝트 로컬 스킬**로 신설.
