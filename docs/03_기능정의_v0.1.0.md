# 주식 트렌드 알림 — 기능정의 v0.1.0

> 요건([01_요건정리_v0.1.0.md](01_요건정리_v0.1.0.md)) 의 F1~F5 를 실제 화면·데이터·API 관점으로 분해.

## 1. 정보 구조 (IA)

```
주식 트렌드 (앱)
├── 🏠 대시보드                (즐겨찾기 요약 + 오늘의 알림)
├── 🔍 종목 검색               (종목명/코드 검색)
├── ⭐ 즐겨찾기                (내 관심 종목 리스트)
├── 📈 종목 상세 (리포트)      (선택 종목 AI 분석)
├── 🔔 알림 이력               (최근 발송 로그)
└── ⚙️ 설정                    (알림 채널·쿨다운 등)
```

- 좌측 사이드바 = 5개 메뉴 고정
- 상단 헤더 = 앱 로고 · 종목 통합 검색바 · 알림 벨(신규 뱃지)

## 2. 기능 상세 (F1 ~ F5)

### F1. 종목 검색 & AI 분석 리포트

#### F1-1. 검색

| 항목 | 값 |
|---|---|
| 진입 | 상단 헤더 검색바 또는 좌측 `🔍 종목 검색` 메뉴 |
| 입력 | 종목명(한글) 또는 종목코드(6자리 숫자) |
| 자동완성 | 2글자 이상 시 최대 8개 서제스트 노출 (종목명 · 코드 · 시장) |
| 액션 | 클릭 시 종목 상세로 이동 |
| 빈 검색 결과 | `해당 종목을 찾을 수 없습니다. 종목명·코드를 확인해주세요.` |

#### F1-2. AI 분석 리포트 (종목 상세 화면)

리포트는 5개 카드로 구성:

| # | 카드 | 표시 데이터 |
|:---:|---|---|
| 1 | **가격 헤드라인** | 종목명 · 종목코드 · 시장 · 현재가 · 등락률 · 거래량 · 시가총액 |
| 2 | **핵심 가격대 다이어그램** | 장기목표가 → 1차저항선 → 현재가 → 지지선 → 손절선 시각화 (수직 스케일) |
| 3 | **가격대별 코멘트** | 1차 목표가/2차 목표가/장기 목표가/지지선/손절선 각각 이유·상승여력·기대 트리거 텍스트 |
| 4 | **대응 가이드** | 추격 매수 주의 · 단계적 익절 · 손절선 관리 규칙 |
| 5 | **차트 (60일 캔들 + 지지·저항 라인)** | 캔들차트 위에 지지선(초록)/저항선(빨강) 오버레이 |

#### F1-3. 리포트 상단 고정 문구

`⚠️ 본 리포트는 규칙 기반 기술적 분석입니다. 투자 판단은 본인 책임이며, 어떠한 수익도 보장하지 않습니다.`

### F2. 즐겨찾기 (Watchlist)

| 항목 | 값 |
|---|---|
| 등록 | 종목 상세 화면 우상단 `⭐ 즐겨찾기` 토글 버튼 |
| 해제 | 동일 버튼 다시 클릭 또는 즐겨찾기 리스트 각 행의 `⋯` → `해제` |
| 저장 위치 | 1차: 브라우저 `localStorage` · 2차: 서버 DB |
| 리스트 컬럼 | 종목명 · 현재가 · 등락률 · 지지선 · 저항선 · 알림 상태 · 액션 |
| 정렬 | 등락률 내림/오름 · 알림 활성순 · 종목명 가나다순 |
| 최대 등록 | 50종목 |
| 빈 상태 | `아직 즐겨찾기한 종목이 없어요. 상단 검색으로 관심 종목을 찾아 ⭐ 를 눌러보세요.` |

### F3. 알림 조건 설정

즐겨찾기한 종목별로 3종 알림 각각 ON/OFF + 임계값 커스텀 가능.

| 알림 유형 | 기본 임계값 | 사용자 편집 |
|---|---|---|
| 🟢 매수 알림 | 1차 저항선 돌파 | 임계 가격 직접 입력 가능 |
| 🔴 매도 알림 | 지지선 이탈 | 임계 가격 직접 입력 가능 |
| ⛔ 손절 알림 | 손절선 이탈 | 임계 가격 직접 입력 가능 |
| 🎯 목표가 도달 (옵션) | 1차 목표가 | 임계 가격 직접 입력 가능 |

- 편집 UI: 종목 상세 우상단 `🔔 알림 설정` → 슬라이드 패널
- 저장: 종목별 최대 4개 알림 조건

### F4. 매수/매도 알림 전송

| 항목 | 값 |
|---|---|
| 감시 주기 | 장중 5분 단위 (09:00 ~ 15:30 KST) |
| 발송 채널 | 1차: **브라우저 Notification API** (앱이 열려 있을 때 즉시) · 2차: 이메일 · Push |
| 중복 방지 | 같은 종목·같은 조건 24h 쿨다운 (설정에서 조정 가능) |
| 알림 카드 UI | 색상 배너 + 종목명 + 트리거 문구 + `상세 보기` · `알림 끄기` 액션 |
| 장 마감 후 | 발송 X. 다음 개장일 첫 5분 배치에서 재평가 |

**알림 문구 템플릿**

```
🟢 [매수 검토] {종목명} {가격}원 돌파 — {트리거 조건 요약}
🔴 [매도 검토] {종목명} {가격}원 이탈 — 지지선 붕괴
⛔ [손절]     {종목명} {가격}원 — 손절선 이탈, 재검토 필요
🎯 [목표 도달] {종목명} {가격}원 — 1차 목표가 달성
```

### F5. 알림 이력

| 항목 | 값 |
|---|---|
| 리스트 컬럼 | 발송 시각 · 종목 · 알림 유형 뱃지 · 트리거 가격 · 트리거 조건 · 상태(읽음/미확인) |
| 필터 | 알림 유형 · 종목 · 기간 (오늘/어제/이번주/커스텀) |
| 정렬 | 최신순 기본 |
| 상세 | 행 클릭 시 우측 슬라이드 패널에 트리거 시점 스냅샷(가격·지지선·저항선) 표시 |
| 일괄 액션 | `읽음 처리` · `보관 삭제` |
| 빈 상태 | `최근 30일 발송된 알림이 없습니다.` |

## 4. API 인터페이스 (핵심)

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/stocks/search?q=...` | 종목 자동완성 |
| GET | `/api/stocks/:code/report` | AI 분석 리포트 (5카드 데이터) |
| GET | `/api/stocks/:code/candles?days=60` | 60일 캔들 |
| GET | `/api/watchlists` | 즐겨찾기 리스트 |
| POST | `/api/watchlists` | 즐겨찾기 등록 |
| DELETE | `/api/watchlists/:code` | 해제 |
| GET | `/api/alert-rules?code=:code` | 종목 알림 조건 |
| PUT | `/api/alert-rules` | 알림 조건 upsert |
| GET | `/api/alert-history?from=&to=&type=` | 알림 이력 |
| POST | `/internal/scheduler/scan` | 5분 배치 — 조건 평가 & 발송 (내부 크론) |

## 5. 상태·에러 정책

| 상황 | 화면 대응 |
|---|---|
| 시세 API 실패 | 리포트 헤더에 노란 배너 `시세를 불러오지 못했습니다. 최근 유효 데이터: {시각}` |
| 장 마감 시간대 | 헤더 우측에 `장 마감 · 종가 기준` 회색 뱃지 |
| 알림 권한 미허용 | 대시보드 상단에 파란 배너 `브라우저 알림을 허용하면 매수/매도 타이밍을 놓치지 않아요` + `허용하기` 버튼 |
| 즐겨찾기 50개 초과 | 등록 시 토스트 `즐겨찾기는 최대 50종목까지 등록 가능합니다.` |

## 6. 안티 패턴 (금지)

- ❌ 수익률·기대 수익 강조 문구 (`+50% 예상!`) — 리스크 유발
- ❌ 알림 배지에 과도한 색상 사용 — 헤이데어 색상 토큰 준수 (success/info/warning/destructive)
- ❌ 자동완성 지연 (500ms 이상) — debounce 200ms 이하 유지
- ❌ 알림 스팸 — 24h 쿨다운 강제, 사용자가 kill switch 로 즉시 종료 가능해야 함
