# 주식 트렌드 알림 — 화면기획 (Storyboard) v0.1.0

> `storyboard_writer` 스킬 양식 준수. 각 화면 = **메인** · **숨은 화면(모달·패널)** · **조건부 분기** 3부분 분리.

## 공통 레이아웃

```
┌─────────────────────────────────────────────────────────────────────┐
│ 🟠 Header: 로고 | [🔍 종목명·코드 통합 검색바      ] | 🔔(3) 프로필 │
├──────────┬──────────────────────────────────────────────────────────┤
│ SideNav  │                                                          │
│ 🏠 대시  │              Main Content Area                           │
│ 🔍 검색  │                                                          │
│ ⭐ 즐겨  │                                                          │
│ 🔔 알림  │                                                          │
│ ⚙️ 설정  │                                                          │
└──────────┴──────────────────────────────────────────────────────────┘
```

- 색상: 헤이데어 브랜드 오렌지(primary) + 뉴트럴 그레이 스케일
- 상태색: success(green) · info(blue) · warning(amber) · destructive(red)

## 화면 1 · 대시보드 (홈)

### 1-M. 메인

| 영역 | 내용 |
|---|---|
| 상단 알림 배너 (조건부) | 브라우저 알림 미허용 시 `허용하기` 배너 (info) |
| 오늘의 알림 카드 | 최근 24h 발송된 알림 3~5건 미리보기 (아이콘 + 종목명 + 트리거 문구 + 시각) |
| 즐겨찾기 요약 그리드 | 최대 6종목 미니 카드 (종목명 · 현재가 · 등락률 · 지지선/저항선 근접 뱃지) |
| 시장 요약 | KOSPI · KOSDAQ 지수 · 등락률 |

### 1-H. 숨은 화면
- **알림 미리보기 모달**: 오늘의 알림 카드 클릭 시 알림 상세 스냅샷 (트리거 시점 가격 + 현재 가격 대비)

### 1-C. 조건부 분기
| 조건 | 화면 |
|---|---|
| 즐겨찾기 0건 | 요약 그리드 자리에 `⭐ 관심 종목을 등록해보세요` 빈 상태 (illustration + CTA) |
| 알림 0건 | 오늘의 알림 카드 자리에 `조용한 하루입니다. 모니터링 중 ...` |
| 장 마감 | 헤더 우측에 회색 뱃지 `장 마감 · 종가 기준` |

## 화면 2 · 종목 검색

### 2-M. 메인

| 영역 | 내용 |
|---|---|
| 검색 입력창 | `종목명 또는 6자리 종목코드를 입력하세요` placeholder, 대형 입력필드 |
| 인기 검색어 (검색 전) | 오늘의 상승률 TOP 10 종목 칩 |

### 2-C. 조건부 분기
| 조건 | 화면 |
|---|---|
| 결과 0건 | `해당 종목을 찾을 수 없습니다. 종목명·코드를 다시 확인해주세요.` |
| API 실패 | 인라인 에러 배너 + `다시 시도` 버튼 |

### 3-H. 숨은 화면
- **알림 설정 슬라이드 패널** (우측에서 슬라이드 인): 3~4개 알림 조건 토글 + 임계 가격 입력. 저장 시 성공 토스트.
- **즐겨찾기 메모 모달**: 즐겨찾기 등록 후 `이 종목에 메모를 남길까요?` (선택)

### 3-C. 조건부 분기
| 조건 | 화면 |
|---|---|
| 시세 API 실패 | 헤더 아래 warning 배너 `시세를 불러오지 못했습니다. 최근 유효 데이터: 2026-09-29 14:35` |
| 즐겨찾기 이미 등록 | 버튼이 채워진 별(★) 로 표시, 클릭 시 해제 |
| 즐겨찾기 미등록 상태에서 알림 설정 시도 | 모달 `알림을 설정하려면 먼저 즐겨찾기에 등록해주세요.` [즐겨찾기 등록] 버튼 |
| 알림 권한 미허용 | 슬라이드 패널 상단에 파란 배너 `브라우저 알림 허용이 필요합니다` |
| 종가 시장 종료 | 헤더에 회색 뱃지 `종가 기준 · 15:30 마감` |

## 화면 4 · 즐겨찾기 리스트

### 4-M. 메인

- **PageHeader**: 제목 `즐겨찾기` · 우측 `[+ 종목 추가]` 버튼
- **StatCard 그리드** (4장, 클릭=필터):
  - 전체 (N)
  - 🟢 매수 임박 (지지선 근접 or 저항선 돌파 시도) (n)
  - 🔴 매도 신호 (지지선 이탈) (n)
  - 🔔 알림 활성 (n)
- **FilterBar**: 시장(KOSPI/KOSDAQ) · 알림 유형 · 검색(placeholder: 등록한 종목명 검색)
- **DataTable 컬럼**:
  | 컬럼 | 내용 |
  |---|---|
  | 종목명 (링크) | 클릭 → 종목 상세 |
  | 현재가 | tabular-nums right |
  | 등락률 | ▲/▼ 색상(success/destructive) |
  | 지지선 | 2,250 |
  | 저항선 | 3,050 |
  | 현재 위치 | 미니 프로그레스 바 (지지↔저항 사이 위치) |
  | 알림 | 🔔 아이콘 (활성 종목만 오렌지) |
  | 액션 | `⋯` → 상세 · 알림 편집 · 해제 |

### 4-H. 숨은 화면
- **알림 편집 슬라이드 패널** (화면 3-H 와 동일 컴포넌트 재사용)
- **해제 확인 모달**: `LS전선을 즐겨찾기에서 해제할까요?` [해제] [취소]
- **일괄 해제 모달** (다중 선택 시): `선택한 3종목을 해제할까요?`

### 4-C. 조건부 분기
| 조건 | 화면 |
|---|---|
| 등록 0건 | L1 빈 상태 (illustration + CTA `종목 검색으로 이동`) |
| 필터 결과 0건 | L3 빈 상태 `조건에 맞는 종목이 없어요` + `필터 초기화` |
| 50종목 초과 시도 | 등록 시 토스트 (destructive) `즐겨찾기는 최대 50종목까지 가능합니다.` |
| 알림 권한 미허용 | 리스트 상단에 파란 배너 + `허용하기` |

  | 컬럼 | 내용 |
  |---|---|
  | 발송 시각 | 2026-09-29 10:32 |

  | 종목 | 종목명 (링크) |
  | 트리거 가격 | 3,050 원 |
  | 트리거 조건 | "1차 저항선 3,000원 돌파" |
  | 상태 | 읽음 / 미확인 (도트) |

### 5-H. 숨은 화면

| 조건 | 화면 |
|---|---|
| 최근 30일 0건 | `조용한 30일이었네요. 종목이 조건을 만족하면 여기에 표시됩니다.` |
| 필터 결과 0건 | `조건에 맞는 알림이 없어요` |

## 화면 6 · 설정

### 6-M. 메인 (섹션 3개)

**섹션 A. 알림 채널**
- 브라우저 알림 (기본 ON, 권한 상태 표기)
- 이메일 알림 (2차, 비활성)
- Push 알림 (2차, 비활성)

**섹션 B. 알림 정책**
- 쿨다운 시간 (기본 24h, 6/12/24/48h 선택)
- 장 마감 후 알림 발송 여부 (기본 OFF)
- 알림 소리 (기본 ON)

**섹션 C. 데이터 관리**
- 검색 이력 지우기 (버튼)
- 즐겨찾기 전체 내보내기 (JSON 다운로드)
- 계정 초기화 (destructive, 확인 모달)

### 6-H. 숨은 화면
- **계정 초기화 확인 모달**: `모든 즐겨찾기·알림 이력이 삭제됩니다. 정말 초기화할까요?` (destructive)

### 6-C. 조건부 분기
- 브라우저 알림 권한 거부 상태: 배너 `브라우저 설정에서 알림을 허용해주세요` + 도움말 링크

## 접근성 (A11y)

- 모든 아이콘 버튼에 `aria-label` 필수
- 색상만으로 상태 구분 금지 — 뱃지 텍스트 병행
- 키보드 탐색: Tab, Enter, ESC(모달 닫기) 지원
- 대비 4.5:1 이상 확보

## 반응형

- 1440px+ : 사이드바 고정 (widescreen)
- 1024px : 사이드바 아이콘만 (collapsed)
- 768px 이하 : 하단 탭바 (2차)
