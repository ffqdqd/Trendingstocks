# 주식 트렌드 알림 서비스 — 요건정리 v0.1.0

> 사용자가 관심 종목을 즐겨찾기하고, 지지선·저항선·목표가 기준의 매수/매도 알림을 받는 개인 투자 보조 서비스.

## 1. 배경

- Gemini(생성형 AI) 로 특정 종목의 지지선·저항선·1차/2차/장기 목표가·손절선을 조회한 결과가 매우 유용했음.
- 매번 AI에 재질의하는 것은 번거롭고 실시간 이탈 감지가 어려움.
- 원하는 종목을 등록해두고, 조건 이탈 시 알림으로 받고 싶음.

## 2. 목표 사용자 (Persona)

| 페르소나 | 특징 | 니즈 |
|---|---|---|
| **개인 스윙 트레이더** (핵심) | 시간이 부족해 상시 감시 불가. 종목 5~20개 관심권에 있음. | 마지노선 이탈 즉시 알림, 매수 타이밍 진입 신호 |
| **저평가주 매집자** | 저점 매수 기회 감지 필요 | 지지선 근접 알림 |
| **손절선 관리자** | 감정적 홀딩 방지, 손절 규율 필요 | 손절선 이탈 즉시 알림 |

## 3. 서비스 한 줄 요약

**"내가 지정한 종목의 매수·매도 타이밍을 AI 분석 기준으로 지속 감시하고, 조건 만족 시 즉시 알려주는 서비스"**

## 4. 핵심 기능 요구 (5개)

| # | 기능 | 필수도 | 설명 |
|:---:|---|:---:|---|
| F1 | **종목 검색 & AI 분석 리포트** | ★★★ | 종목명/코드 입력 → 현재가 · 지지선 · 저항선 · 목표가 · 손절선 자동 산출 리포트 노출 |
| F2 | **즐겨찾기 (Watchlist)** | ★★★ | 관심 종목 등록/해제, 리스트 정렬, 그룹핑(옵션) |
| F3 | **알림 조건 설정** | ★★★ | 종목별로 매수/매도/손절 알림 켜기·끄기. 임계 가격 커스텀 |
| F4 | **매수/매도 알림 전송** | ★★★ | 조건 만족 시 브라우저 알림 · (선택) 이메일/Push 발송 |
| F5 | **알림 이력 (History)** | ★★ | 최근 알림 발송 기록, 재알림 방지(같은 조건 24h 쿨다운) |

## 5. 비기능 요구

| 항목 | 요구 |
|---|---|
| 성능 | 종목 상세 리포트 조회 3초 이내 |
| 데이터 소스 | 국내 주식(코스피/코스닥) 우선. 시세 15분 지연 허용 가능(무료 API 기준) |
| 감시 주기 | 장중(09:00~15:30) 5분 간격 배치. 실시간 아님 |
| 접근성 | PC 웹 브라우저 우선. 모바일 반응형은 2차 |
| 로그인 | 1차는 로컬 저장(단일 사용자). 2차 계정제 확장 |
| 알림 채널 | 1차 브라우저 Notification API. 2차 이메일·Push |

## 6. 데이터 소스 후보

| 후보 | 장단점 | 채택 |
|---|---|:---:|
| **네이버 금융 크롤링** | 무료·풍부하나 ToS 위반 소지 | ❌ |
| **한국투자증권 KIS OpenAPI** | 무료·공식·실시간. 계좌 필요 | ⭐ 1차 |
| **DBSecu / 대신증권 API** | 유사 조건 | 보조 |
| **Yahoo Finance (yfinance)** | 국내 종목 지원 취약 | 참고만 |
| **금융감독원 OpenDART** | 재무제표용 | 재무 지표 보조 |

> **MVP 는 KIS OpenAPI 로 시세만 받고, AI 분석 리포트는 규칙 기반(기술적 지표 + 52주 고저 + 이동평균) 으로 산출.** 완전 생성형 코멘트는 2차.

## 7. AI 분석 리포트 산출 로직 (MVP 규칙 기반)

| 값 | 산출 방식 |
|---|---|
| 현재가 | 최근 종가 |
| 주요 지지선 | 52주 최저가 근처 + 최근 60일 저점 밴드 |
| 1차 저항선 | 최근 60일 매물대 밀집 구간(거래량 가중) |
| 장기 목표가 | 52주 신고가 부근 (재무 흑자전환 힌트가 있으면 상향) |
| 손절선 | 지지선 -3% ~ -5% 하단 |
| 코멘트 | 위 값들 조합한 규칙 기반 템플릿 문장 |

## 8. 알림 트리거 조건

| 유형 | 조건 | 예시 문구 |
|---|---|---|
| 🟢 매수 알림 | 현재가가 **1차 저항선** 돌파 (당일 종가 기준) | `[매수 검토] LS전선 3,050원 돌파 — 1차 저항선 통과. 3,200원까지 여력 +5%` |
| 🔴 매도 알림 | 현재가가 **주요 지지선** 이탈 | `[매도 검토] LS전선 2,090원 이탈 — 지지선 붕괴. 손절선 근접` |
| ⛔ 손절 알림 | 현재가가 **손절선** 이탈 | `[손절] LS전선 1,995원 — 손절선 이탈. 재검토 필요` |
| 🎯 목표가 도달 | 현재가가 **1차/장기 목표가** 도달 | `[목표가 도달] LS전선 3,200원 — 1차 목표가 달성. 익절 검토` |

**중복 방지**: 동일 종목·동일 조건 24시간 쿨다운.

## 9. 범위 (Scope)

### 1차 (MVP) — 이번 화면 기획 대상
- 종목 검색 (코스피/코스닥, 종목명·코드)
- AI 분석 리포트 화면 (규칙 기반)
- 즐겨찾기 등록/해제
- 종목별 알림 조건 ON/OFF
- 브라우저 알림
- 알림 이력 리스트

### 2차 (제외)
- 계정제 로그인
- 이메일/Push/Slack 알림
- 재무제표 기반 상향/하향 코멘트
- 종목 그룹핑, 태그
- 백테스팅
- 커뮤니티 코멘트

## 10. 성공 지표 (KPI)

| # | 지표 | 목표 |
|:---:|---|---|
| K1 | 즐겨찾기 등록 종목 수 (사용자당) | 평균 10개 이상 |
